# Manual DMX channel test

Choose **DMX test** from a viewport's View type dropdown, or **Output → Channel test**. Choose a zero-based universe and the first channel (one-based), then **Arm channel test**. The panel displays16 channel sliders. Each touched slider overrides that raw DMX byte (0–255); untouched channels keep their evaluated scene levels. Paging preserves up to32 tested channels. Test master scales only those test levels. **Zero tested channels** holds tested slots at0; **Release channel** or **Release test** returns them to the scene. Universe changes release the old test.

Output routing, enabling and refresh rate stay under Output → Connection. Test sliders never enable hardware output. Disabled output remains capture-only. Levels feed the same snapshot/universe transport bytes for Art-Net and Windows Open DMX USB; fixture model mapping/daily dimming run first, and manual test bytes replace selected slots afterwards. Fixture program/control slots are raw DMX slots as well. Blackout forces tested slots to0.

Channel tests are transient runtime inputs, not project edits or undo entries. A single panel owns the active test lease. Slider requests keep only one in flight and the latest pending value/release. Moving sliders and a1-second heartbeat renew a5-second lease; a competing panel receives an ownership error. Releasing, closing the panel/dialog, hiding the page or switching panel type stops the test. If a client disappears or the release request fails, the engine automatically restores the scene after5 seconds. Test leases are excluded from session serialization and do not restart after reopening a project/service. The output status explicitly identifies an active TEST universe/channel count.

The authenticated `/api/inputs` event is `{type:"channel_test",owner:"panel-id",universe:0,channels:{"1":128}}`. Each message replaces that owner's complete override set. Empty channels release it. Universe range0–32767, channel range1–512, maximum32 slots, byte values0–255, owner1–64 ASCII letters/digits/underscores/hyphens. Existing API authentication and origin checks apply.

Verification covers deterministic lease expiry/ownership/limits, blackout, identical project/history/revision, omitted session lease, and real loopback ArtDmx capture/release. Browser tests exercise desktop/phone slider forms, master, zero/release, end-of-universe addressing and close cleanup without physical output. Hardware fixture response is not implied.
