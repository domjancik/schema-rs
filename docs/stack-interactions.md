# Stack placement and Cursor

Implementation follows the review in `scnq-schema/codex/analysis/schema-rs-cursor-drag-review.md`, coordinated with **Analyze Schéma visual stacking and interactions**. Pure geometry derives from prototype `schema-stack-lab` commit `e4d6ae8`, adapted to numeric IDs, preorder layout, separate driver scopes and engine transactions.

Desktop blocks use one filled SVG outline, studs at child-span centers and a matching recessed output socket. Shared row pitch and block height remove the former gap. Each parent exposes N+1 ordered input-boundary + controls; below-block + wraps that specific branch. Picker destinations and revisions are captured when opened. The backend accepts optional AddInput.index; omission retains append behavior. Current frontend creation/moves use immutable Batch/ReplaceLayer plans so they also work with the older running engine.

Pointer dragging carries a floating branch label, faint source origins and an inert projected tree. Projection uses a cloned draft from the same move planner as commit; no preview commands are sent to the engine. Original logical target rectangles remain fixed during projected space-making. Exact plus areas win at boundaries; underside seams select wrapping without requiring Alt. Shift drags a single block and promotes its old inputs. Pointer cancellation, Escape and blur discard the preview. Drop commits one captured-revision batch; stale changes are rejected and refresh the view. Driver drop targets retain property validation. Reduced-motion settings disable reflow animation.

In schémaboy Stack/Select, arrows and D-pad move a single logical cell; vertical movement retains column. A inserts before the child interval under that cell. Hold/Shift+A lifts only that child into a new wrapper. Wide spans [1,2,1] map cells [0,1,2,3] to indices [0,1,1,2]. Tap mapping inverts the SVG group transform. Empty cells have no structural destination. Folded children occupy one visible cell; a folded parent's A explicitly appends to its hidden input list rather than choosing an invisible child. Inspector actions retain explicit Append input and wrap-this-block choices. Fixture/layer/driver contexts reset or clamp the local cursor. Cursor navigation is UI state and adds no engine undo entries; authored structural edits remain undoable.
